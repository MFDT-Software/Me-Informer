🇷🇺 Русская версия

Me Informer — утилита для установки произвольного статуса Discord Rich Presence, разработанная командой {MFDT} на базе SFML и discordpp.

Основные возможности
- Discord Rich Presence — установка пользовательского текста активности в Discord.
- Персонализация — ввод никнейма и приветствие по времени суток.
- Двуязычный интерфейс — быстрое переключение между RU/EN.
- История статусов — до 10 последних статусов с навигацией стрелками ↑/↓.
- Шифрованное сохранение — язык, никнейм и история хранятся в скрытом .dat с XOR-шифрованием.
- Текстовый ввод — каретка, стрелки ←/→, Home/End, Backspace, Enter.
- Простой GUI — окно SFML, кнопки выхода и смены языка.
- Автосохранение — изменения сохраняются при подтверждении действий.
- Локальная работа — не требует сетевого режима, работает совместно с Discord.

🇬🇧 English Version

Me Informer is a utility for setting a custom Discord Rich Presence status, developed by the {MFDT} team using SFML and discordpp.

Key Features
- Discord Rich Presence — set custom activity text in Discord.
- Personalization — nickname input and time-of-day greeting.
- Bilingual Interface — fast RU/EN toggle.
- Status History — up to 10 latest statuses with ↑/↓ navigation.
- Encrypted Saving — language, nickname, and history are stored in a hidden .dat file with XOR encryption.
- Text Input — caret, ←/→ arrows, Home/End, Backspace, Enter.
- Simple GUI — SFML window, exit and language switch buttons.
- Auto-save — changes are saved after confirmation.
- Local Operation — no network mode required, works together with Discord.
